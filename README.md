# 文字だけポケモン対戦シミュレーター v3

開発者が登録したデータだけを使い、開発者が作成したアカウントでのみ利用できるサーバー型テキストバトルです。

## v3で実装した本格化

- タイプ相性（効果なし / いまひとつ / ばつぐん）
- 物理 / 特殊 / 変化技
- 攻撃・防御・特攻・特防・素早さ
- 素早さによる行動順
- 技の優先度
- 命中率
- STAB
- 天候（あめ / はれ）
- 状態異常: やけど、まひ、どく、もうどく、ねむり、こおり
- 能力変化（攻撃・防御・特攻・特防・素早さ）
- 代表的な特性効果:
  - いかく `intimidate`
  - ちからもち `huge_power`
  - すいすい `swift_swim`
  - ようりょくそ `chlorophyll`
  - もうか `blaze`
  - げきりゅう `torrent`
  - あめふらし `drizzle`
  - ひでり `drought`
  - ふゆう等の特殊処理は今後拡張可能
- 代表的な持ち物効果:
  - たべのこし `leftovers`
  - いのちのたま `life_orb`
  - こだわりスカーフ `choice_scarf`
- 技効果:
  - まもる
  - 回復
  - つるぎのまい
  - わるだくみ
  - りゅうのまい
  - ひるみ
  - 状態異常付与
- 6匹→3匹選出
- バトル状態・HP・勝敗はサーバー側管理

## 開発者画面

`/admin`

フォームからポケモン、特性、持ち物、技、相手パーティ、プレイヤーアカウントを登録できます。

ポケモンにはタイプ、特性ID、技ID、ステータス、初期持ち物を登録できます。
技にはタイプ、威力、分類、命中率、優先度、効果、状態異常を登録できます。

## 起動

```bash
npm install
npm start
```

Node.js 20以上。

本番では `SESSION_SECRET`、`ADMIN_USERNAME`、`ADMIN_PASSWORD` を変更し、HTTPSリバースプロキシの後ろで運用してください。

## ルールについて

これは公式ゲームを完全再現するエンジンではなく、サーバー型の独自シミュレーターです。世代・作品を指定した厳密な公式ルール（個体値、努力値、性格、持ち物・特性・技の全効果、ダメージ乱数等）へ寄せる場合は、対象世代とルールセットを固定して追加実装してください。


## v4: HTML単体化

`public` 配下のページは、CSSとJavaScriptをそれぞれHTMLへ直接埋め込んでいます。

- `login.html` → HTML内にCSS/ログインJSを内蔵
- `app.html` → HTML内にCSS/対戦JSを内蔵
- `admin.html` → HTML内にCSS/管理JSを内蔵
- 独立した `style.css` / `app.js` / `admin.js` は不要

そのため、各ページは「HTMLファイル単体でCSSとJSを含む」構成です。
認証・対戦処理・データ保存そのものは従来どおりサーバー側で行います。


## v4.1: ログイン後の画面遷移
