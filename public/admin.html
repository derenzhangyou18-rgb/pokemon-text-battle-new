ポケモン・技・特性・持ち物・相手パーティをフォームから登録できます。JSONを直接入力する必要はありません。

登録の考え方

IDは英数字で分かりやすく付けてください。たとえば「10まんボルト」のIDを thunderbolt にしたら、ポケモンの技欄でも同じIDを選びます。フォームで選択した内容は、対戦エンジンが使うデータ形式に変換してSupabaseへ保存されます。

アカウント

GitHub Pages版ではパスワードを独自DBに保存せず、Supabase Authを使用します。開発者権限はSupabase SQL Editorで設定します。
