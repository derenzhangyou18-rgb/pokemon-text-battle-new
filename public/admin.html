開発者管理

Supabaseに登録データを保存します。既存データはJSONでまとめて移行できます。

対戦サイト

データ管理

JSONの中身は既存シミュレーターのデータ形式をそのまま利用できます。1レコード=1件としてSupabaseへ保存されます。

アカウント

GitHub Pages版ではパスワードを独自DBに保存せず、Supabase Authを使用します。新規アカウントはログイン画面の「新規登録」から作成してください。開発者権限はSupabase SQL Editorで update public.profiles set role='developer' where username='...'; を実行します。
