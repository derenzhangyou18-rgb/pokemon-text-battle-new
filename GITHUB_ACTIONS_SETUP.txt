【GitHub Actions 復旧手順】

今回の重要ポイント：GitHub Actions は .github/workflows/ の中に .yml/.yaml ファイルが必要です。
Webから通常の「ファイルをアップロード」で隠しフォルダ .github が抜けることがあるため、確実にするにはGitHub上でworkflowファイルを1回作成します。

1. GitHubのリポジトリを開く
2. 「Add file」→「Create new file」
3. ファイル名に次を入力
   .github/workflows/pages.yml
4. このZIP内の DEPLOY_WORKFLOW.yml の中身を全部コピーして貼り付ける
5. 「Commit changes」を押す
6. Actionsを開く
7. 「Deploy GitHub Pages」が表示される
8. 「Run workflow」→ main → Run workflow

このworkflowはリポジトリ全体（path: .）をGitHub Pagesへ公開します。
ルートの index.html が公開対象になるので、今回の構成に合っています。
