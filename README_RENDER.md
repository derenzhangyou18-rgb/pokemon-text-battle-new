## Renderへの公開方法

### 方法1: Blueprintを使う（推奨）

1. このフォルダをGitHubリポジトリにアップロードします。
2. Renderで「New → Blueprint」を選びます。
3. GitHubリポジトリを接続します。
4. リポジトリ直下の `render.yaml` を使って作成します。
5. デプロイが完了するまで待ちます。
6. Renderが表示する `https://....onrender.com` を開きます。
7. `deveropper0510` / `1` でログインします。

`render.yaml` にはNode.js 20、起動コマンド、ヘルスチェック、SQLite用永続ディスク、必要な環境変数が設定されています。

## 注意

SQLiteのデータを再デプロイ後も保持するため、RenderのPersistent Diskを使用しています。Persistent Diskが利用できるWeb Serviceプランで運用してください。

管理画面から登録したポケモン・技・特性・持ち物・相手パーティ・プレイヤーアカウントはSQLiteに保存されます。

パスワード `1` はテスト用として非常に弱いため、インターネットへ本格公開する場合はRenderの `ADMIN_PASSWORD` を強いパスワードへ変更してください。

## ローカル起動

```bash
npm install
npm start
```

ブラウザで `http://localhost:3000` を開きます。

## Node.js version
Renderでbetter-sqlite3のビルドがNode.js 26になって失敗しないよう、Node.js 20.19.5に固定しています。
`.node-version` と package.json の engines を使用します。
